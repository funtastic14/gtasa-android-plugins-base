# Frame animation

The numbered PNGs are complete frames for one synchronized pair of eyes. Play in lexical/numeric order:

`eyes_000.png` → `eyes_001.png` → `eyes_002.png` → `eyes_003.png` → loop.

All frames use the same 96x32 canvas. The intended settings are frame duration and loop mode. Frame playback is planned and not yet supported by the current runtime.
